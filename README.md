# Danil Forge — Product Lab

Интерактивная коллекция самостоятельных портфельных продуктов: веб-интерфейсы, рабочие инструменты и автоматизация.

- Открывайте демо прямо в браузере через GitHub Pages.
- Исходники подготовленных продуктов находятся в `projects/`.
- Клиентских данных и закрытых проектов в репозитории нет.

## Первая волна

ReportKit, Stockroom, Clientspace, Leadline, Queue, Lineup Support, Relay, Public Watch, Operator UI Kit, Storefront Lab, SheetFlow, DocForge, Catalog Watch и Content Patch.

## Исходники

В публикации доступны 20 пакетов исходников: ReportKit, Relay, Groundlog, TracePin, Batch Studio, Release Dock, Signal Bot, FieldDesk, Booking Desk, Clientspace, Stockroom, Leadline, Access Hub, SyncBridge, Knowledge Desk, Storefront Lab, SheetFlow, DocForge, Catalog Watch и Content Patch. У каждого продукта есть собственная инструкция запуска. Если отдельный файл лицензии отсутствует, действует корневая лицензия репозитория.
