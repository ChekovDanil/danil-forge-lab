# Catalog Watch

Локальное интерактивное демо сравнения двух снимков публичного каталога. Первый синтетический снимок представлен HTML, второй — JSON. Приложение разбирает записи, удаляет дубли, сравнивает выбранные поля и экспортирует результат в CSV.

## Возможности

- безопасный разбор контролируемого HTML-fixture;
- разбор JSON-fixture без сетевых запросов;
- выбор отслеживаемых полей: название, цена и наличие;
- дедупликация по SKU с явным счётчиком дублей;
- статусы «новое», «изменено», «удалено» и «без изменений»;
- фильтрация результата и локальный CSV-экспорт;
- адаптивный интерфейс без внешних библиотек.

## Запуск тестов

```bash
npm test
```

Статическая версия находится в `public/`, чистое ядро — в `src/catalog-watch.js`.

## Граница безопасности

Проект не обращается к внешним сайтам, не использует авторизацию, cookies, прокси, браузерную автоматизацию и не обходит защиту. Все записи вымышлены и встроены в приложение. Реальное подключение допустимо только к источнику, который явно разрешает автоматический доступ, через официальный API, предоставленный экспорт или после письменного согласования с владельцем источника.
