# Storefront Lab

A framework-free responsive storefront for a synthetic home-office collection. The project demonstrates a complete browser flow without external services or customer data.

## Included

- searchable and sortable product catalog;
- category filters and an explicit empty state;
- accessible product quick view;
- persistent local cart with quantity controls;
- shipping threshold and local demo checkout;
- desktop, tablet, and mobile layouts.

All products, descriptions, prices, and order identifiers are fictional. The demo does not call an API, accept payment, or send personal data.

## Run

```bash
npm start
```

Open `http://127.0.0.1:3440`. Run the pure logic tests with `npm test`.
