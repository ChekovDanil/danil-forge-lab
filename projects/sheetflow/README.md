# SheetFlow

Автономное браузерное демо сверки двух таблиц. Оно показывает, как сопоставить разные названия колонок, найти совпадения и расхождения и выгрузить результат в CSV. Все данные синтетические; файлы и внешние API не используются.

## Возможности

- два демонстрационных набора: реестр заказов и отчёт платежей;
- ручное сопоставление трёх ключевых колонок;
- сравнение идентификатора, email и суммы;
- отдельные статусы для совпадений, отличий, пропущенных и лишних строк;
- фильтр всех строк, ошибок и совпадений;
- локальный CSV-экспорт, безопасный для открытия в Excel;
- адаптивный интерфейс без внешних библиотек.

## Проверка

```bash
npm test
```

Статическое демо находится в `public/`. Для просмотра откройте каталог через любой локальный статический сервер. Вся логика сверки находится в `src/sheetflow.js` и не зависит от DOM.

## Граница демо

SheetFlow не читает реальные XLSX-файлы и не подключается к банкам, CRM или облачным таблицам. Это интерактивная демонстрация сценария сверки на синтетических данных. Импорт XLSX и интеграции относятся к отдельной реализации под формат заказчика.
