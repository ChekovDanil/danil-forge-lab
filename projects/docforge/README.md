# DocForge

Небольшой генератор коммерческого предложения, счёта и акта из одной формы. Данные в демо вымышлены и обрабатываются только в браузере.

## Возможности

- единый набор реквизитов для трёх документов;
- расчёт суммы, НДС и итога;
- переключение предпросмотра;
- экспорт автономного HTML-пакета и JSON-манифеста;
- печать выбранного документа в PDF средствами браузера.

Откройте `public/index.html` или запустите любой статический сервер в каталоге `public`.

```bash
npm test
```
