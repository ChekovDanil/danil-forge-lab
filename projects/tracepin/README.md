# TracePin

Manifest V3 расширение для фиксации точных правок по сайтам. Выделенный текст, очищенный URL, тип замечания, приоритет, проект, теги и комментарий сохраняются только в `chrome.storage.local` и могут быть собраны в QA-бриф.

## Что готово

- context-menu capture выделенного текста;
- page picker после явного клика;
- popup с поиском и последними правками;
- options/library с фильтрами и редактированием;
- Markdown и JSON export;
- очистка URL, дедупликация и локальный soft limit;
- минимальные разрешения без `host_permissions`;
- отдельное web demo на том же domain core;
- 26 автоматических тестов.

## Локальный запуск web demo

```bash
node server.mjs
```

Открыть `http://127.0.0.1:3280/`.

## Проверка

```bash
npm test
```

Тесты проверяют доменное ядро, минимальные разрешения Manifest V3, CSP, локальное хранение, экспорт и устойчивость последовательной записи.

## Установка расширения

1. Открыть страницу управления расширениями Chromium.
2. Включить режим разработчика.
3. Выбрать «Загрузить распакованное расширение».
4. Указать папку `extension/`. ZIP для release собирается отдельно из этой же папки после ручной проверки.

Web demo показывает сценарий, но не выдаётся за установленное расширение. Для финальной публикации отдельно проверяются реальная загрузка unpacked, сохранение после перезапуска браузера и picker на разрешённой HTTP(S)-странице.
