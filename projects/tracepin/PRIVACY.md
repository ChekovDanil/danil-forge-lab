# TracePin — privacy boundary

- Данные хранятся только в `chrome.storage.local`; аккаунта, сервера, аналитики и телеметрии нет.
- Расширение не запрашивает широкие `host_permissions` и работает на странице только после явного действия пользователя через `activeTab`.
- Не сохраняются cookies, localStorage страницы, raw HTML, полный DOM, скриншоты, значения password/input/textarea/contenteditable.
- URL по умолчанию очищается от userinfo, query и hash.
- Локальное хранилище не является шифрованным: секреты и персональные данные сохранять нельзя.
- Экспорт выполняется только по явному действию пользователя и никуда автоматически не отправляется.
