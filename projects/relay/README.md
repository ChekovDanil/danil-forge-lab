# Relay

Собственный демонстрационный продукт: движок пошаговой заявки и веб-симулятор Telegram-диалога. Показывает полную логику квалификации и маршрутизации без подключения тестового токена.

## Реализовано

- последовательный сценарий: имя, контакт, категория, описание, бюджет, срок и подтверждение;
- четыре категории и четыре бюджетных диапазона;
- проверка телефона, email и содержательности описания;
- возврат к редактированию и полная отмена сценария;
- автоматический выбор команды, ответственного и рабочего канала;
- обычный и высокий приоритет с разным SLA;
- структурированная карточка заявки вместо технического payload;
- журнал событий и следующий понятный шаг для команды;
- адаптивный интерфейс для ПК и мобильного;
- 12 автоматических тестов доменной логики.

## Запуск

```bash
npm test
npm start
```

Симулятор: `http://127.0.0.1:3020`.

Для реального запуска доменный движок подключается к Grammy, базе данных и разрешённому каналу уведомлений. В портфолио это обозначено как следующий интеграционный этап, а не как уже работающая внешняя интеграция.
