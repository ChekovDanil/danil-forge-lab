# Batch Studio

Локальная очередь реальной пакетной подготовки изображений для сайтов и маркетплейсов.

## Что работает

- JPEG, PNG и WebP определяются по сигнатуре;
- два версионированных recipe: Web delivery и Marketplace square;
- три выходных варианта на исходник;
- без увеличения маленьких изображений;
- автоматическое применение ориентации;
- metadata не переносится в результаты;
- JPEG получает явный фон при наличии alpha;
- FIFO-очередь продолжает работу после закрытия вкладки, пока запущен сервер;
- пауза, продолжение, отмена, повтор одного failed item и исключение;
- ошибка одного файла не останавливает пакет;
- input/output SHA-256 и повторное чтение каждого результата;
- скачиваемые manifest JSON и настоящий ZIP;
- 16 автоматических тестов.

## Запуск

```bash
npm ci
npm start
```

Продукт откроется на `http://127.0.0.1:3300/`.

## Проверка

```bash
npm test
```

`node_modules/` и локальный npm-кэш не входят в публикационный пакет и восстанавливаются через `npm ci`.

## Честная граница

Это single-node локальный продукт с очередью в памяти. Закрытие вкладки не мешает worker, но остановка сервера сбрасывает незавершённое состояние. Нет аккаунтов, S3/CDN, распределённых workers, RAW/PSD/PDF/video, AI-upscale, ручной ретуши, печатной цветокоррекции и антивирусной проверки. Для production нужны durable storage, изолированные job directories, recovery после рестарта и обновляемая политика лимитов.
