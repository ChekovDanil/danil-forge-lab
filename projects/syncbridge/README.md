# SyncBridge

Small synchronization core and browser demo for mapping records between services. It previews payloads, retries temporary failures, records outcomes, and prevents duplicate successful writes.

## Run locally

```bash
npm start
```

Run the tests with `npm test`; run the command-line example with `npm run demo`.

The repository contains local adapters and sample data, not production credentials.
