# Signal Bot

Рабочий портфельный пример Telegram-бота мониторинга. Доменная логика, сценарии, API и интерфейс выполняются локально; реальная отправка в Telegram не подключена и не изображается как готовая.

## Что реализовано

- состояния healthy / degraded / down;
- один активный инцидент на сервис;
- группировка повторных проверок;
- тихие часы для предупреждений;
- немедленная доставка критического сбоя;
- временное приглушение сервиса;
- подтверждение ответственного;
- автоматическое закрытие после восстановления;
- три воспроизводимых сценария и preview сообщений.

## Запуск

```bash
npm start
```

Открыть `http://127.0.0.1:3400/`.

## Проверка

```bash
npm test
```

## Граница

Для реального проекта добавляются Telegram Bot API, хранение состояния, авторизация команд, планировщик проверок, секреты окружения, rate limits и наблюдаемость доставки.
