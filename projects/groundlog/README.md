# Groundlog

Offline-first PWA для полевых записей. Интерфейс сохраняет изменения локально, формирует очередь синхронизации и не скрывает конфликт, если одна запись была изменена на двух устройствах.

## Что работает

- установка как standalone PWA;
- IndexedDB как авторитетное локальное хранилище;
- создание и редактирование без сети;
- компактная outbox-очередь со стабильными mutation ID;
- optimistic revision на демонстрационном сервере;
- защита от повторного применения одной операции;
- явный конфликт local/remote версий;
- три решения конфликта: оставить серверную, повторить локальную или объединить вручную;
- Service Worker кэширует оболочку, но не API и пользовательские изменения;
- 22 автоматических теста доменной и offline-логики.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm test
npm start
```

Приложение откроется по адресу `http://127.0.0.1:3320/`.

Для проверки offline-сценария создайте запись, переключите состояние сети внутри демо, измените запись и вернитесь в онлайн. Для конфликта сначала измените серверную версию, затем отправьте локальную операцию с предыдущей revision.

## Архитектура

- `public/idb.js` — локальная база и outbox;
- `src/sync-core.js` — чистая доменная логика версий, операций и конфликтов;
- `server.mjs` — локальный демонстрационный API и статические файлы;
- `public/service-worker.js` — offline app shell;
- `test/` — PWA-инварианты и полный lifecycle синхронизации.

## Честная граница

Это самостоятельный локальный демонстрационный продукт, а не production cloud-сервис. Удалённая сторона хранится в памяти одного Node.js-процесса. Здесь не заявляются авторизация, multi-tenant база, шифрование локальных данных, гарантированный background sync, push-уведомления, durable queue или горизонтальное масштабирование. Эти слои проектируются отдельно под реальное окружение.
