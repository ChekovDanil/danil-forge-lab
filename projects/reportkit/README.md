# ReportKit

Небольшая рабочая утилита для проверки и нормализации CSV. Собственный демонстрационный продукт: данные обрабатываются локально и не отправляются на сервер.

## Возможности

- автоматическое определение `;`, `,` или табуляции;
- корректное чтение кавычек и разделителей внутри значения;
- загрузка реального CSV до 2 МБ;
- автоматическое и ручное сопоставление русских, английских и нестандартных колонок;
- нормализация российских телефонов, дат и денежных сумм;
- сохранение проблемных строк с объяснением;
- фильтры готовых и проблемных строк;
- отдельный экспорт чистых данных и отчёта ошибок;
- восемь автоматических тестов ядра обработки.

## Запуск

```bash
npm test
npm start
```

Демо откроется по адресу `http://127.0.0.1:3010`.
